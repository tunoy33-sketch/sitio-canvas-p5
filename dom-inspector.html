DOM Inspector

El árbol del DOM de cada página del sitio, dibujado desde el nodo raíz <html> hasta sus elementos más profundos. Elige una página y haz clic en un nodo con el botón «+» para desplegar sus hijos.

Elemento Contenedor semántico Canvas

Cómo funciona

Al elegir una página, el inspector la descarga con fetch() y convierte su código HTML en un documento con DOMParser, el mismo mecanismo con el que el navegador construye el DOM real. Después recorre de forma recursiva la propiedad children de cada elemento, calcula la posición de cada nodo para que los padres queden centrados sobre sus hijos y dibuja el resultado como un gráfico SVG. Los nodos de texto y los comentarios se omiten para que se vea solo la jerarquía de etiquetas. Como el inspector usa fetch(), funciona cuando el sitio está publicado (por ejemplo en GitHub Pages) o se sirve con un servidor local, pero no al abrir el archivo directamente con doble clic.
