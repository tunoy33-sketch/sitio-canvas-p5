Del simulador de Khan Academy al código web real

Este sitio reúne los cinco dibujos que realicé en los retos de Khan Academy, ahora reescritos con código web estándar: HTML para la estructura, CSS para el diseño y JavaScript con la biblioteca p5.js para el dibujo y la interacción.

Cada dibujo vive en su propia página y se renderiza dentro de una etiqueta <canvas>, con su código p5.js al lado, como en el editor de Khan Academy.

Cómo está organizado el proyecto

El código fuente se divide en tres tipos de archivo. Las páginas HTML están en la raíz del proyecto, la hoja de estilos compartida está en la carpeta css y los scripts están en la carpeta js, donde cada dibujo tiene su propio archivo dentro de js/sketches. Esa separación permite que el menú, el diseño y la lógica de dibujo se modifiquen de forma independiente.
