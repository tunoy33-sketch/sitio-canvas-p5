Fundamentos de p5.js

La biblioteca que convierte el canvas en una herramienta cómoda para la programación creativa.

¿Qué es p5.js?

p5.js es una biblioteca de JavaScript de código abierto para programación creativa. Fue iniciada por Lauren Lee McCarthy en 2013 y se inspira en Processing, el entorno creado por Casey Reas y Ben Fry en 2001 para enseñar programación a artistas y diseñadores. Hoy la mantiene la Processing Foundation junto con una amplia comunidad. Su objetivo es que dibujar, animar y reaccionar a la interacción del usuario requiera muy pocas líneas de código, sin necesidad de dominar la API de bajo nivel del navegador. Para usarla basta con cargar el archivo de la biblioteca antes del script propio; este sitio la toma de una red de distribución de contenido (CDN) en su versión 1.9.4: 

<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.9.4/p5.min.js"></script>
<script src="js/sketches/rana.js"></script>

Estructura de un programa: setup() y draw()

Un programa de p5.js gira en torno a dos funciones que la biblioteca invoca automáticamente. setup() se ejecuta una sola vez al iniciar y sirve para preparar el lienzo con createCanvas(ancho, alto), que es la instrucción que crea el elemento <canvas> dentro de la página. draw() se ejecuta en bucle, por omisión sesenta veces por segundo, y es donde vive la animación. Cada pasada de draw() suele comenzar con background(), que borra el cuadro anterior. La variable frameCount cuenta cuántos cuadros se han dibujado, y funciones como noLoop(), loop() y frameRate() permiten detener, reanudar o ajustar el ritmo del bucle. 

function setup() {
  createCanvas(400, 400).parent('lienzo');   // crea el canvas dentro del div#lienzo
}

function draw() {
  background(135, 206, 235);
  circle(mouseX, mouseY, 40);                // un círculo que sigue al mouse
}

Coordenadas y formas primitivas

p5.js usa el mismo sistema de coordenadas que el canvas, con el origen arriba a la izquierda. Las formas básicas son point(), line(), rect(), ellipse(), circle(), triangle(), quad(), arc() y las curvas bezier(), además de beginShape(), vertex() y endShape() para polígonos personalizados. Hay un detalle que suele provocar errores: ellipse(x, y, ancho, alto) recibe el centro de la elipse, mientras que rect(x, y, ancho, alto) recibe su esquina superior izquierda, aunque ambos comportamientos pueden cambiarse con ellipseMode() y rectMode(). Los ángulos se expresan en radianes por defecto, para lo cual existen las constantes PI, HALF_PI y TWO_PI.

Color y estilo

El estilo en p5.js es un estado global: lo que se establece con fill() (relleno), stroke() (contorno) y strokeWeight() (grosor) se aplica a todas las figuras siguientes hasta que se cambie. Para quitar el relleno o el contorno se usan noFill() y noStroke(). Los colores se pueden dar como un valor de gris, como tres valores RGB, como RGB con transparencia, como texto hexadecimal o, tras llamar a colorMode(HSB), como matiz, saturación y brillo. Los dibujos de este sitio usan el formato RGB, por ejemplo fill(30, 204, 91) para el verde de la rana. Las funciones color() y lerpColor() permiten guardar un color y mezclar dos de ellos, y el texto se escribe con text(), textSize() y textAlign().

Transformaciones y la pila de estados

translate(), rotate() y scale() no mueven figuras ya dibujadas: modifican el sistema de coordenadas para todo lo que se dibuje a continuación. Como esos cambios se acumulan, p5.js ofrece push() y pop(), que guardan y restauran el estado (transformaciones y estilos). El patrón habitual consiste en abrir un bloque con push(), trasladar el origen al punto de pivote de la figura, rotarla, dibujarla y cerrar con pop(). El orden importa: trasladar y luego rotar no produce el mismo resultado que rotar y luego trasladar.

Interactividad y utilidades matemáticas

p5.js pone a disposición del programa variables del sistema que siempre contienen el estado actual de la entrada: mouseX y mouseY (posición del cursor dentro del lienzo), pmouseX y pmouseY (posición en el cuadro anterior), mouseIsPressed, key y keyIsPressed. También se pueden definir funciones de evento con nombres reservados, como mousePressed(), mouseMoved() o keyPressed(), que la biblioteca llama justo cuando ocurre el suceso. Para trabajar con los valores existen map() (convierte un valor de un intervalo a otro), constrain(), lerp(), dist(), random() y noise(), además de las funciones trigonométricas sin(), cos() y atan2(), indispensables para calcular movimientos y trayectorias.

Modo global y modo instancia

Los dibujos de este sitio usan el modo global, en el que setup() y draw() se declaran directamente como funciones de la página y todas las instrucciones de p5.js están disponibles sin prefijo. Es el modo más sencillo y el más cercano a Khan Academy, pero tiene un inconveniente: contamina el espacio global y solo admite un dibujo por página. El modo instancia resuelve ese problema envolviendo el programa en una función que recibe un objeto, tradicionalmente llamado p, del cual cuelgan todas las instrucciones. Se crea con new p5(sketch) y permite tener varios dibujos independientes en la misma página. La demostración siguiente está escrita en modo instancia. 

new p5((p) => {
  p.setup = () => {
    p.createCanvas(480, 260).parent('demo-p5');
  };
  p.draw = () => {
    p.background(20);
    p.circle(p.mouseX, p.mouseY, 30);
  };
});

Ver el código de la demostración (demo-p5.js)

Relación entre p5.js y canvas

p5.js no sustituye al elemento <canvas>: lo utiliza. Al llamar a createCanvas(), la biblioteca crea un canvas, obtiene su contexto 2D con getContext('2d') y traduce cada una de sus funciones a llamadas del contexto nativo. Por ejemplo, circle() acaba ejecutando beginPath(), arc(), fill() y stroke(). La biblioteca añade comodidades como el estilo global, el bucle de animación, el ajuste a pantallas de alta densidad y las variables de entrada. Cuando se necesita una función que p5.js no ofrece, la propiedad drawingContext da acceso directo al contexto 2D nativo. Con createCanvas(ancho, alto, WEBGL) la biblioteca cambia al contexto WebGL para trabajar en tres dimensiones.

De Khan Academy a este sitio

El simulador de Khan Academy ofrece un entorno cerrado: el lienzo ya existe, las funciones de dibujo están disponibles y el código se ejecuta con un botón. Para llevar los dibujos al código web estándar fue necesario añadir lo que el simulador hacía de forma implícita: una página HTML con un contenedor para el lienzo, la carga de la biblioteca y una función setup() con createCanvas(400, 400). Como los cinco dibujos son escenas fijas, no necesitan la función draw(): p5.js ejecuta setup() una sola vez y el dibujo queda en el lienzo.

Hay una diferencia que conviene conocer: el fondo por omisión del simulador es blanco, mientras que el de p5.js es gris claro, por lo que en los dibujos que no definían un fondo (la rana, los dientes de conejo y el muñeco de nieve) se agregó background(255). El resto de las instrucciones, como fill(), ellipse() o rect(), conservan su forma original, lo que demuestra que lo aprendido en el simulador es directamente transferible al entorno real.
